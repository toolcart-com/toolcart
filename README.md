# ToolCart V1.5

This package contains ToolCart V1.5 — Apple-Inspired Beauty Rebuild.

## Apply to existing project

If you already have ToolCart deployed, upload the contents of **ToolCart-V1.5-Changes-Only** to the root of your GitHub repository and replace the matching files.

## No migration required

There is no new D1 migration for V1.5.

## After deploy

1. Wait for Cloudflare to show **Ready**.
2. Open the site once and refresh it again to let the new service worker replace the old cached shell.
3. If Safari still shows an old layout, close the tab and reopen the site.
